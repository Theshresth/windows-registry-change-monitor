Windows Registry Change Monitoring System

A Python-based cybersecurity project for monitoring registry changes.

Developed by Shresth Soni

Project Overview

This project demonstrates registry change monitoring on Windows using a dedicated test registry key. It records detected changes and provides basic heuristic analysis of suspicious autorun entries.

Key Features

  • Detects added, modified and deleted test registry values.
  • Logs registry events for review.
  • Includes baseline and SHA-256 integrity-checking components.
  • Provides basic heuristic analysis of autorun entries.

Technology Stack

Python, Windows Registry, JSON, SHA-256 and Windows Command Prompt.

Important Note

This page documents the project; it does not run the Python monitor in a browser. The monitor must be executed on a compatible Windows system. Its heuristic analysis is not a guarantee of malware detection.
